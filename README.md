# Piano VR para Terapia

Aplicación de realidad virtual que simula un piano virtual con una función pensada para terapia, dentro de un ambiente inmersivo. Proyecto final de semestre desarrollado en equipo en la FIME-UANL.


## Tecnologías

- Unity
- C#
- Realidad virtual (visor VR y emulador de dispositivo VR)

## Mi participación

Fui parte de un equipo de 8 personas. Mi trabajo se enfocó en:

- Desarrollo de los movimientos del usuario en realidad virtual.
- Creación de algunas de las escenas.
- Implementación de los sonidos de las escenas.
- Apoyo en las físicas del piano.

## Cómo abrir el proyecto

1. Clona este repositorio.
2. Ábrelo con Unity Hub usando la versión 6000.3.11f1.
3. La primera vez tardará en abrir, porque Unity regenera archivos del proyecto.
4. Para probarlo, usa un visor de realidad virtual o un emulador de dispositivo VR.

## Nota

El proyecto fue diseñado para usarse con un visor de realidad virtual y se hicieron pruebas con uno. También funciona con un emulador de dispositivo VR en la computadora.
